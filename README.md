# 지름신 퇴치소

사고 싶은 물건, 구독, 명품·보석, 주식·코인, 여행 같은 경험을 입력하면 충동구매인지 따져 주는 웹앱이에요.

**바로 써 보기: https://jirumsin.com/**

## 할 수 있는 것

- **세계 보유율 추정**: 전 세계에서 몇 명 중 한 명이 가졌는지, 한국 추정치, 추정 범위, 근거, 신뢰도
- **판정 부적**: 결제 중지 · 72시간 보류 · 재고 요망 · 통과, 충동 지수(0~100)와 점수 근거
- **구매 심리 분석**: 지금 작동하는 심리와 '사실 원하는 것'
- **결제 전 영수증**: 숨은 비용, 되팔 때 남는 값, 노동 시간, 10년 뒤 기회비용, "치킨 ○마리" 환산
- **영수증 이미지**: 판정 도장이 찍힌 영수증을 SNS용 그림(폭 1080px)으로 저장하거나 휴대폰 공유 시트로 바로 보내기
- **설렘 유통기한 그래프**, 사기 전에 해 볼 것, 1년 뒤의 나에게서 온 편지
- **보류함**(24시간~30일 타이머)과 **참은 돈 저금통**(목표 설정)
- **Claude 정밀 분석**과 **지름신과 담판 짓기**: claude.ai 아티팩트에서 열었을 때만 동작해요. GitHub Pages 주소에서는 앱에 담긴 통계로 분석해요.

## 파일 구성

| 파일 | 내용 |

| `src/head.html`, `src/body.html` | 페이지 머리와 화면 뼈대 |

| `src/style-1.css`, `src/style-2.css` | 색 토큰(밝은·어두운 모드)과 화면 스타일 |
| `src/data-items.js` | 품목별 보유율·가격 통계(한 줄에 한 품목) |
| `src/data-cats.js` | 분류별 기본값, 심리 설명, 예시 |
| `src/engine.js` | 품목 찾기, 비용 계산, 충동 지수, 이유와 편지 만들기 |
| `src/render.js` | 결과 화면 그리기 |
| `src/ai.js` | Claude 정밀 분석과 담판 대화 |
| `src/card.js` | 공유용 영수증 그림 그리기, 저장·공유 창 |
| `src/app.js` | 신고서, 결정 바, 보류함, 저금통, 화면 전환, 익명 통계 이벤트(`track`) |
| `build.sh` | 조각을 합쳐 `index.html`과 `docs/index.html`을 만들어요 |
| `src/og.html`, `og.sh` | 링크 공유 미리보기 그림 `docs/og.png`(1200×630)의 원본과 찍는 스크립트 |
| `src/icon.html`, `icon.sh` | 휴대폰 홈 화면 아이콘(`docs/apple-touch-icon.png`, `icon-192.png`, `icon-512.png`)의 원본과 찍는 스크립트. 앱 이름과 아이콘 목록은 `docs/manifest.webmanifest`에 있어요 |

## 빌드와 미리보기

```bash
./build.sh
```

- `index.html`: claude.ai 아티팩트 게시용이에요(문서 머리 없이 본문만 있어요).
- `docs/index.html`: GitHub Pages가 보여 주는 완전한 페이지예요. 로컬에서도 브라우저로 바로 열어 볼 수 있어요.

소스는 `src`에서 고치고, 고친 뒤에는 `build.sh`를 다시 실행해요. 링크 미리보기 그림은 `src/og.html`을 고친 뒤 `./og.sh`로 다시 찍어요(Google Chrome과 인터넷 연결이 필요해요). 다시 찍었으면 `src/web-head.html`의 `og:image` 주소 끝 `?v=` 숫자를 하나 올려 주세요. 카카오톡은 같은 주소의 그림을 오래 기억해서, 주소가 바뀌어야 새 그림을 가져가요. 홈 화면 아이콘은 `src/icon.html`을 고친 뒤 `./icon.sh`로 다시 찍어요. `docs/index.html`이 바뀐 채로 `main`에 올라가면 GitHub Pages도 1~2분 뒤에 새 버전으로 바뀌어요.

## 익명 사용 통계

GitHub Pages판에만 [Umami](https://umami.is) 추적 코드가 들어 있어요(`src/web-head.html`). claude.ai 아티팩트판에는 없어요. `data-domains="jirumsin.com"`이라서 그 주소에서 연 방문만 세고, 로컬 미리보기나 다른 주소에 복사된 페이지에서는 보내지 않아요. 도메인을 바꾸면 이 값도 함께 고쳐 주세요.

- 이벤트는 `src/app.js`의 `track()`으로 보내요: `analyze`, `decide`, `share`, `wait_action`, `open_wait`, `open_jar`, `jar_goal_set`, `feedback`.
- 입력한 품목 이름, 정확한 가격, 시급, 저금통 목표 이름은 보내지 않아요. 사전에 없는 품목은 `other`로, 가격은 만 원 단위 구간(`under3`, `3to10`, `10to50`, `50to200`, `over200`)으로만 보내요.
- 내 방문 빼기: 주소 끝에 `?notrack=1`을 붙여 한 번 열면 그 브라우저의 방문은 통계에서 빠져요. `?notrack=0`으로 열면 다시 잡혀요. 브라우저(기기)마다 따로 해야 해요.
- 결과 화면 맨 아래 피드백 버튼(👍 👎)과 바닥글의 통계 안내는 Pages판에서만 보여요.

## 알아 둘 점

- 보유율·가격·하락폭은 공개 자료와 업계 추정치를 바탕으로 한 대략적인 값이라 실제와 다를 수 있어요.
- 주식·코인 분석은 투자 권유가 아니라 충동적인 결정을 막기 위한 위험 점검표예요.
- 보류함과 저금통 기록은 쓰는 브라우저의 localStorage(`jirumsin.v1`)에만 저장돼요.
- 색은 WCAG AA 대비(글자 4.5:1, 입력칸 테두리 3:1)에 맞춰 골랐어요. 색을 바꿀 때는 밝은·어두운 모드 대비를 다시 확인해 주세요.
